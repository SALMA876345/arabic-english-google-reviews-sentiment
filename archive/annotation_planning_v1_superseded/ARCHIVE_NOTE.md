# Archived: 2-Annotator Planning Iteration (Superseded)

These files are the project's original RQ3 human-validation plan, designed around **two** independent annotators. Mid-task, the project pivoted to **three** independent bilingual annotators plus a blinded fourth adjudicator (see `docs/decisions.md`, the interrupting instruction documented in that log). At the time of the pivot, `annotator_1_blinded.csv` and `annotator_2_blinded.csv` were still fully blank (zero real annotation labels existed), so no data was lost in the switch.

This planning iteration was never executed and is retained here only for provenance (it documents the reasoning trail that led to the final 3-annotator + adjudicator design actually used, which lives in full in `paper/annotation/full/`). It is not part of the reproducibility pipeline for any reported result.

**Contains review text (Arabic and English) in the two blank CSVs** — kept out of version control for the same reason as the equivalent files under `paper/annotation/full/` (see root `.gitignore` and `paper/notes/DATA_LICENSING_AND_RELEASE.md`).
